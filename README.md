# TaskList CLI

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

TaskList CLI — простое консольное приложение на Python для управления списком задач. Оно позволяет добавлять, просматривать, отмечать выполненными и удалять задачи.

## Возможности
- Добавление задач
- Просмотр списка задач
- Отметка задачи как выполненной
- Удаление задач
- Автоматическое сохранение задач в JSON-файл

## Установка и запуск

Нужен Python 3.10 или новее.

```bash
python main.py
```

Если команда `python` не работает в Windows, попробуйте:

```bash
py main.py
```

## Команды управления

После запуска вводите номер действия в меню:

| Команда | Действие |
|---|---|
| `1` | Добавить задачу |
| `2` | Показать все задачи |
| `3` | Отметить задачу выполненной |
| `4` | Удалить задачу |
| `0` | Выйти из программы |

При добавлении задачи введите её название. Для выполнения или удаления задачи введите её номер из списка.
