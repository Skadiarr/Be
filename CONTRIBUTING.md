# Руководство по внесению вклада

Спасибо за интерес к TaskList CLI!

## Сообщение об ошибке
1. Откройте Issue.
2. Опишите проблему и шаги её воспроизведения.
3. Укажите ожидаемый и фактический результат.

## Предложение изменений
1. Сделайте Fork репозитория.
2. Создайте ветку: `git checkout -b feature/NewFeature`.
3. Внесите изменения и проверьте программу.
4. Создайте коммит: `git commit -m "Describe changes"`.
5. Отправьте ветку: `git push origin feature/NewFeature`.
6. Откройте Pull Request.

## Стиль кода
- Используйте понятные имена функций и переменных.
- Следуйте PEP 8.
- Проверяйте изменения перед отправкой.
- Добавляйте комментарии к сложным участкам кода.
