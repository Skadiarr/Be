# Архитектура TaskList CLI

## Общая информация
TaskList CLI — консольное приложение на Python для управления задачами.

## Компоненты
- **Пользовательский интерфейс:** показывает меню и получает команды.
- **Управление задачами:** добавляет, отображает, завершает и удаляет задачи.
- **Хранение данных:** сохраняет задачи в файл `tasks.json` в формате JSON.

## Принцип работы
1. При запуске программа загружает задачи из `tasks.json`, если файл существует.
2. Пользователь выбирает команду в меню.
3. Программа выполняет выбранную операцию.
4. Изменения сохраняются в JSON-файл.
5. Работа продолжается до выбора выхода.

## Архитектурное решение
Для учебной версии выбран простой консольный интерфейс и JSON-хранилище. Это позволяет обойтись без дополнительных библиотек и легко изучать структуру проекта.
